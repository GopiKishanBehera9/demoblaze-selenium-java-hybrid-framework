# Demoblaze Selenium Java Hybrid Framework

Enterprise Selenium Automation Framework using:

- Java 21
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Apache POI
- Log4j2
- Allure Report

## Framework Features

- Page Object Model (POM)
- Hybrid Framework
- Data-Driven Testing
- Cross Browser Testing
- Parallel Execution (Upcoming)
- ThreadLocal WebDriver (Upcoming)
- Jenkins Integration (Upcoming)
- GitHub Actions (Upcoming)
